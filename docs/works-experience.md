# 作品体験の更新（2026-09-08）

## 元画像の配置

- 実際の元画像を `public/images/origin-romaco.png` に配置して再ビルドすると、中央の起点カードに表示されます。
- 現時点では画像ファイル未配置。RCのモノグラムと「元画像は準備中」を表示します。別の画像を元画像と偽って使用しません。
- 配置済みでも読み込みに失敗した場合は同じフォールバックを表示します。
- 表示枠は正方形。画像全体が見えるように表示し、コピーと3分岐の接続線を添えています。

## 動画再生

- YouTube動画カードは、共通のネイティブdialog内で再生します。プレーヤーはクリック時に初めて生成します。
- 16:9の埋め込み枠、autoplay=1、playsinline=1を指定。実際の自動再生可否はブラウザーやYouTube側の制限に従います。
- 閉じるボタン、背景クリック、Escで閉じ、iframeを削除します。フォーカスと元のスクロール設定を復元します。
- YouTubeへの直接リンクと、作品タイトル・動画URLを含むX共有リンクをモーダル内に配置しています。
- JavaScript無効時やdialog非対応時は元の外部リンクとして機能します。修飾キー付きクリックも維持します。
- 元画像・漫画のリンク動作は変更していません。

## 検証範囲

`tests/unit/video-modal.test.ts` で、クリックの捕捉、埋め込みURL、スクロールロック、3種類の閉じ方、iframe削除、フォーカス復帰、再オープン、共有リンクをコードレベルで検証します。YouTubeの映像・音声の実再生やブラウザー固有の挙動をモックテストが保証するものではありません。
